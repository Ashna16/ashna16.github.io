Credit Analysis Portal

A full-stack credit risk intelligence tool that automates the manual document processing workflows performed by financial analysts every month and quarter.

Upload any financial document — 10-K, income statement, balance sheet, cash flow statement, or covenant report — and the system automatically extracts every financial field, assigns a per-field confidence score, calculates 12 credit risk ratios across liquidity, leverage, coverage, profitability, and cash flow categories, flags covenant breaches, and outputs a credit decision with a policy-approved loan limit.

Built to solve a real problem in credit monitoring: a 168-page Microsoft 10-K processed in 20 seconds, returning a full risk assessment that would otherwise take an analyst hours of manual work.

Tech Stack: Python · FastAPI · pdfplumber · PostgreSQL · SQLAlchemy · Docker · Streamlit · Figma

Strava-Your Personal AI Trainer

💻

I built Live Coach for Strava: a real-time voice agent designed to fill the "mid-run" feedback gap.🏃‍♀️🏃

Strava is the gold standard for tracking. But while you're hitting "the wall" at mile 4, it stays silent. It only tells you what went wrong after the run is over.

The result? An agent that actually intervenes during your run

HandOff

It's an autonomous offboarding agent for the moment an employee resigns. Instead of critical knowledge walking out the door, Handoff maps everything they own, finds what would "die with them," interviews them about the reasoning that never made it into a doc, and then actually executes the rescue — reassigning work, booking transfer sessions, and notifying the team.

🧠 FalkorDB — the memory layer. Everything the departing engineer owns becomes a live knowledge graph, so we can run the query that matters most: "which systems have only one human who understands them?" That's the risk map.
⚡ LaserData — the real-time and context layer. The resignation event streams in, every action the agent takes streams back out as a durable, replayable event — and it doubles as the context layer feeding the exit interview, so the reasoning captured live becomes shared context the rest of the pipeline can draw on.
🚀 RocketRide — the motion layer. It orchestrates the entire pipeline end to end: analyze → interview → plan → execute, sequencing every step so the "memory" actually turns into "motion."
🤝 Guild.ai — the human-facing layer. This is where the agent reaches into the real world — reassigning live Jira tickets, sending emails, dropping Slack notices, and scheduling handover meetings. Watching a real Jira board reassign itself on stage was the moment it clicked for everyone.
🧩 OpenAI powered the reasoning underneath it all — grading interview answers, extracting how someone thinks from their own commit history, and answering questions across the entire knowledge graph.
