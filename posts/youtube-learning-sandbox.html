YouTube Learning Sandbox

Practice the code without leaving the tutorial

Open on YouTubeLinkedIn postCode on GitHub

YouTube is one of the best places to learn to code, but the format hasn't changed in over a decade.

You open a tutorial, set up your editor, hit an error, switch tabs to fix it, come back, lose your place, and somewhere in all that the actual learning gets lost.

The idea

What if YouTube had an Interactive Sandbox Mode? Pause the tutorial, open a live sandbox, and try the code yourself, right there. Run it, get hints, no tab-switching, no separate editor. I built a working MVP to test it out.

How it was built

  • Codex built the full YouTube-style UI and checkpoint logic
  • YouTube IFrame Player API for a real embedded video with playback control
  • Monaco Editor, the same editor that powers VS Code
  • Piston API for live code execution
  • OpenAI API generates each challenge and hint from the video content itself

If YouTube owned the full loop (watch, practice, get feedback), it stops being just where you discover a skill and becomes where you actually get good at it.
